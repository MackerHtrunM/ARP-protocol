# ARP 小小網路探險隊｜網站設計簡報

## 品牌定位

- **名稱**：ARP 小小網路探險隊
- **一句話**：用封包動畫認識 ARP，並看懂有人冒充時會發生什麼事。
- **對象**：國中生、第一次接觸網路基礎的學習者
- **語氣**：像一起拆解網路謎題的社團學長姐，親切、有趣、不用艱深術語
- **核心概念**：IP 像通訊錄上的姓名，MAC 像教室裡實際找到人的座位標籤。ARP 幫區域網路把兩者配對。

## 學習目標

1. 說出 ARP 解決的問題：在區域網路中，找到某個 IPv4 位址對應的 MAC 位址。
2. 看懂 ARP Request 廣播詢問和 ARP Reply 回覆的基本流程。
3. 分辨 ARP 訊息內的目標 MAC（未知時留空）和乙太網路標頭的廣播 MAC。
4. 說明 IP/MAC 兩層地址、ARP 快取命中/未命中，以及跨網段時會解析下一站閘道的 MAC。
5. 說明 ARP spoofing 如何利用沒有身分驗證的 IP/MAC 聲明誤導快取，以及可能造成的中間人路徑或斷線。
6. 認識 ARP Probe 的用途與網路管理員可採用的防護方式，例如交換器的 Dynamic ARP Inspection。

## 網站結構

網站使用五個獨立頁面，頂端導覽列和章節切換按鈕都能換頁。

1. **首頁 `index.html`**：一句生活化問題、網路插畫，以及四個章節入口。
2. **ARP 是什麼 `arp.html`**：以雙欄課程工作台呈現 IP/MAC 生活比喻、重點提示與課程進度。
3. **封包實驗室 `lab.html`**：左側封包拓樸、右側步驟講解；快取命中、快取未命中與假冒情境；逐步播放 Request、Reply、送出資料；透視 opcode、乙太網路目的 MAC、ARP 發送者/目標欄位，並即時更新小安的 ARP 快取。
4. **ARP 欺騙解謎 `spoof.html`**：比較正確配對與被污染的快取，展示流量可能經過冒充者或遭到阻斷，並介紹 DAI 防護。
5. **快問快答 `quiz.html`**：十題由基礎到進階的封包判讀挑戰，涵蓋跨網段、ARP Probe、快取污染與 DAI，每題立即解析。
6. **延伸閱讀**：在 ARP 入門和測驗頁提供 RFC 與 Cisco 技術文件。

## 視覺方向

- **方向名稱**：暖色網路課程工作台
- **感受**：參考課程工作台的雙欄資訊層級與步驟導覽，再保留可愛網路節點、圓角卡片與親切比喻；封包實驗室左側看網路拓樸，右側讀當前步驟。
- **色彩**：暖炭黑與深咖啡作為底色，鼠尾草綠代表正常封包與前進操作，珊瑚橘代表假冒警示，奶油白呈現主要文字，柔和藍紫作為輔助標籤。保留清楚的文字對比。
- **字體**：系統中文字體優先，搭配等寬字體呈現 IP/MAC 等封包資訊。
- **版面**：每個主題獨立成頁；桌機和手機都保留可切換的導覽。ARP 入門和封包實驗室採左側主視覺、右側講解面板，底部提供進度或章節切換。
- **畫面高度**：桌機與較高的手機視窗以單畫面課程台呈現，將內容放入固定可視高度；短視窗仍保留自然捲動與可讀字級，避免把內容硬縮到難以閱讀。
- **動態**：封包在裝置間移動，步驟可手動前進、播放與重設；尊重 `prefers-reduced-motion`。

## 互動規格

- **步進播放**：每次只送出一個事件，搭配目前封包欄位與白話解說。
- **自動播放**：依序播放正常 ARP 流程，按鈕狀態清楚。
- **情境切換**：正常 / 假冒情境使用相同拓樸，比較可信回答和錯誤回答造成的差異。
- **回到起點**：清除動畫和模擬快取，方便重看。
- **測驗**：選項按下後立即顯示解釋，重試可重新作答。
- **封包判讀**：每個模擬步驟同步標示 L2 目的 MAC、ARP opcode、發送者與目標 IP/MAC，以及快取中目前記住的配對。
- **可及性**：互動有文字標籤與焦點樣式；動畫可減少；不以顏色作為唯一狀態提示。

## 技術與部署

- 原生 HTML、CSS、JavaScript，無打包工具與第三方執行時依賴。
- 頁面各自使用獨立 HTML 檔案與網址，導覽透過一般連結換頁。
- `serve.py` 用 Python 標準函式庫提供本機預覽。
- GitHub Pages 直接從 repository 根目錄提供靜態檔案。
- 所有封包都是瀏覽器內的教學動畫，不會在真實網路上傳送封包。

## 內容依據

- RFC 826 描述 ARP 用來將協定位址（例如 IP）轉換成區域網路位址（例如 Ethernet MAC），並列出 request/reply 欄位。
- RFC 826 的接收流程會在判斷 opcode 前處理發送者地址資訊；教學同時提醒實際作業系統可能加入額外檢查。
- RFC 5227 定義 ARP Probe 和位址衝突偵測，Probe 的 sender IP 使用 0.0.0.0。
- Cisco Dynamic ARP Inspection 文件說明交換器可利用 DHCP Snooping 綁定資料或 ARP ACL 檢查配對；防護效果取決於正確設定與啟用範圍。
- **AI 網站案例**：OpenAI Showcase 的 [Below the Surface](https://learn.chatgpt.com/showcase/below-the-surface) 把主互動和深度導航做得清楚，並把可靠來源放在容易找到的位置；[Living Cell](https://learn.chatgpt.com/showcase/living-cell-cross-section) 用可檢視結構與緊湊控制解釋複雜機制。本專案採用可檢視的封包欄位、明確步驟狀態與簡潔情境選擇，不照搬其 3D 場景或長頁捲動，因本課程要滿足一屏檢視需求。
- 視覺參考：Dilum 的親切、俏皮個人網站；web-design-skill 導讀的先定方向再整理網站結構的方法。
