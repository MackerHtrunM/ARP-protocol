# ARP 小小網路探險隊｜網站設計簡報

## 品牌定位

- **名稱**：ARP 小小網路探險隊
- **一句話**：用封包動畫認識 ARP，並看懂有人冒充時會發生什麼事。
- **對象**：國中生、第一次接觸網路基礎的學習者
- **語氣**：像一起拆解網路謎題的社團學長姐，親切、有趣、不用艱深術語
- **核心概念**：IP 像通訊錄上的姓名，MAC 像教室裡實際找到人的座位標籤。ARP 幫區域網路把兩者配對。

## 學習目標

1. 說出 ARP 解決的問題：在區域網路中，找到某個 IPv4 位址對應的 MAC 位址。
2. 看懂 ARP Request 廣播詢問和 ARP Reply 回覆的基本流程。
3. 說明 ARP spoofing 如何用錯誤的 IP/MAC 配對誤導裝置，以及可能造成的攔截或斷線。
4. 認識網路管理員可以採用的防護方式，例如交換器的 Dynamic ARP Inspection。

## 網站結構

1. **Hero**：一句生活化問題＋「開始探險」入口；右側小網路插畫。
2. **ARP 是什麼**：IP/MAC 生活比喻、名詞卡、區域網路範圍提示。
3. **封包實驗室**：正常查詢與「有人冒充」切換；逐步播放 Request、Reply、送出資料；封包欄位即時說明。
4. **Spoofing 解謎**：比較正確配對與被污染的快取，展示流量可能經過冒充者或遭到阻斷。
5. **防護小隊**：網路管理員如何運用 DAI 檢查 ARP 對照資料，以及一般使用者可做的基本安全習慣。
6. **三題快問快答**：立即回饋答題結果。
7. **來源與延伸閱讀**：RFC、Cisco 技術文件及設計參考。

## 視覺方向

- **方向名稱**：可愛網路實驗室
- **感受**：有科技感、明亮易讀、像一本互動式探索手冊；使用圓角網路節點、貼紙式標籤、小人物路由器，不做冷硬的終端機介面。
- **色彩**：深靛藍作為穩定底色，亮青綠代表正常封包，珊瑚橘代表警示，淡薰衣草與淺黃提供區塊層次。對比符合一般文字閱讀需求。
- **字體**：系統中文字體優先，搭配等寬字體呈現 IP/MAC 等封包資訊。
- **版面**：寬螢幕雙欄閱讀、窄螢幕單欄；每個區塊先給一個清楚問題，再用圖示或互動回答。
- **動態**：封包在裝置間移動，步驟可手動前進、播放與重設；尊重 `prefers-reduced-motion`。

## 互動規格

- **步進播放**：每次只送出一個事件，搭配目前封包欄位與白話解說。
- **自動播放**：依序播放正常 ARP 流程，按鈕狀態清楚。
- **情境切換**：正常 / 假冒情境使用相同拓樸，比較可信回答和錯誤回答造成的差異。
- **回到起點**：清除動畫和模擬快取，方便重看。
- **測驗**：選項按下後立即顯示解釋，重試可重新作答。
- **可及性**：互動有文字標籤與焦點樣式；動畫可減少；不以顏色作為唯一狀態提示。

## 技術與部署

- 原生 HTML、CSS、JavaScript，無打包工具與第三方執行時依賴。
- `serve.py` 用 Python 標準函式庫提供本機預覽。
- GitHub Pages 直接從 repository 根目錄提供靜態檔案。
- 所有封包都是瀏覽器內的教學動畫，不會在真實網路上傳送封包。

## 內容依據

- RFC 826 描述 ARP 用來將協定位址（例如 IP）轉換成區域網路位址（例如 Ethernet MAC），並列出 request/reply 欄位。
- Cisco Dynamic ARP Inspection 文件說明 ARP 可以因非請求回覆造成快取污染，也說明交換器能檢查 ARP 對照以防範 spoofing。
- 視覺參考：Dilum 的親切、俏皮個人網站；web-design-skill 導讀的先定方向再整理網站結構的方法。
